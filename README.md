Entry for the [One Word, First Thought](https://make.fun/c/u-0xkianno-one-word-first-thought-106abaf8) bounty on make.fun.

The program writes exactly one word — the first word that came to mind — to `/output/entry.txt`:

**psithurism** — the sound of wind whispering through the trees.

## Run

```sh
npx tsx main.ts
```

Writes `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
